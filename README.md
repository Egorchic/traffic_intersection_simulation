# Traffic Intersection Simulation

Учебная дискретно-событийная имитационная модель четырёхстороннего регулируемого перекрёстка на Python/SimPy.

## Возможности первой версии

- 4 независимых пуассоновских потока автомобилей;
- 4 FIFO-очереди (N, S, E, W);
- фиксированный цикл NS (30 с) / жёлтый (3 с) / все красные (1 с) / EW (30 с) / жёлтый / все красные;
- случайные интервалы проезда, 2 секунды до первого проезда в каждой зелёной фазе;
- регистрация ожидания, средней длины очередей и пропускной способности за час;
- после прекращения поступления автомобилей модель опустошает накопленные очереди.

## Запуск в PyCharm

1. Откройте каталог проекта в PyCharm.
2. Создайте виртуальное окружение `.venv` с Python 3.10 или новее.
3. В терминале проекта: `python -m pip install -r requirements.txt`.
4. Запустите `main.py`.
5. Для тестов: `python -m unittest discover -s tests -v`.

Начальные параметры находятся в классе `Config` (`traffic_sim/model.py`). Пока реализован только фиксированный контроллер.
